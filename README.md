# MIRCO STUDIO — Editorial Edition (v6)

A sophisticated content studio for @mirco9015 — story-driven music creator.

## Design Philosophy
Editorial magazine aesthetic. Inspired by Apple Music editorial, NYT, Behance.
- Cormorant Garamond serif typography
- Warm gold accent on monochrome base
- Minimal lines · generous whitespace · bold headlines
- "Issue" and "Catalog" metaphor for content management

## Tabs
- **Forge** — Compose new issues (batch generate)
- **Catalog** — Browse complete works
- **Strategy** — Editorial direction & roadmap
- **Schedule** — Publishing calendar

## Advanced Features
- Issue-based composition (batch up to 10 tracks)
- Track thumbnails with first generated visual
- Real-time generation status
- Sequential numbering (№001, №002...)
- Pull-quote concept display
- Magazine-style image grids
- One-click Suno / Image / TikTok actions
- In-browser video composition (1080×1920, 60s, hearts effect, lyrics, watermark)
- Posted/Published tracking
- JSON data export for backup

完全無料・APIキー不要。
