### Kling運用フロー
1. **画像をダウンロード** — 4枚をiPhoneに保存
2. **Klingで動画化** — プロンプトCOPY → Kling起動 → 5秒動画×4本生成 (無料)
3. **動画クリップを4本アップ** — ツールに一括選択でアップ
4. **音源も指定** — Sunoのmp3
5. **Compose Video** — 動画+音源+歌詞+ハート+透かしで合成
