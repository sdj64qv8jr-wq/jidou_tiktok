# MIRCO STUDIO · 物語楽曲ジェネレーター

柊ミナ × 天羽ルイの物語を軸に楽曲・歌詞・画像・動画・投稿文を一括生成。

## 物語のコア
中学時代に天才的歌声を持っていた柊ミナ(17)は、13歳の事故で母を意識不明にしてしまい、その日から声を失った。4年後、路上で歌い続ける同い年のギタリスト・天羽ルイと出会う。彼の耳もまた、ゆっくりと音を失いつつあった。声を失った少女と耳を失う少年が、それでも音楽を始め、4年間眠り続ける母の病室に歌を届けようとする物語。
